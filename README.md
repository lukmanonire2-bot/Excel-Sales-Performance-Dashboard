# TWDP Sales Performance Dashboard

Project Overview

An interactive sales performance dashboard developed using Microsoft Excel to analyse and visualise business sales data.

The project uses a training dataset to explore revenue, profitability, product performance and sales trends.

Key Performance Indicators (KPIs)

* Total Revenue: ₦40,249,900
* Total Profit: ₦8,655,900
* Total Orders: 45
* Total Units Sold: 559

Dashboard Visualisations

* Revenue by Category
* Revenue by Payment Method
* Revenue by Salesperson
* Revenue by City
* Monthly Revenue Trend
* Top 5 Products by Revenue

Interactive Features

A city slicer allows users to explore sales performance across different locations.

Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Visualisation

Project Objectives

* Evaluate overall sales performance.
* Compare revenue across product categories.
* Examine sales distribution across cities.
* Monitor monthly revenue trends.
* Identify top-performing products.

Conclusion

This project demonstrates how Microsoft Excel can be used to transform sales data into an interactive dashboard that supports business performance monitoring and informed decision-making.
